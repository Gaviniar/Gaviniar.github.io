# Gavin's Blog

> 小舟从此逝，江海寄余生

液态玻璃 × 瑞士国际主义网格个人博客，内置西幻雪山庄园 12 幕原生四季×晨昏深夜光影引擎、东八区北京时间六时段自动同步、以及实时风雪火星动态粒子。

- 在线访问：https://gaviniar.github.io/
- 本地开发：`npm install && npm run dev`
- 生产构建：`npm run build`

## 目录说明

- `src/data/siteConfig.js`：站点名称、简介、近况与碎碎念
- `src/data/posts.js`：博客文章与技术攻略
- `public/assets/manor-{spring|summer|autumn|winter}-{day|golden|night}.jpg`：12 张四季三光影原生背景原画
- `SCENE_PROMPTS.md`：12 张背景原画的完整出图与编辑 Prompt 指南
